## Repository Purpose

This repository has two purposes:

1. Learning
   Build a deep practical understanding of Apache Maven.

2. Demonstration
   Provide tangible evidence of Maven knowledge through
   executable projects, troubleshooting labs and real-world
   build scenarios.


# Mastering Apache Maven

> A hands-on Maven laboratory for Java, CI/CD and DevSecOps.

This repository documents a practical journey through Apache Maven,
from fundamental concepts to production-oriented Java builds.

The goal is not simply to learn Maven commands, but to understand
how Maven works internally and how to use it effectively from the
terminal.

## What this repository demonstrates

- Maven project structure
- POM configuration
- Dependency management
- Dependency scopes
- Transitive dependencies
- Dependency conflict resolution
- Build lifecycle
- Plugins and goals
- Maven Wrapper
- Profiles
- Parent POMs
- Dependency management
- Multi-module projects
- Spring Boot
- CI/CD
- Build quality and security
- Troubleshooting


Built and maintained Maven projects across multiple Java versions, including dependency management, lifecycle customization, plugin configuration, multi-module builds, troubleshooting, reproducible builds and CI/CD integration.
