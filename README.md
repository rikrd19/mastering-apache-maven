# Mastering Apache Maven

> A hands-on Maven laboratory for Java, CI/CD and DevSecOps.

## Repository Purpose

This repository has two purposes:

1. **Learning:** Build a deep, practical understanding of Apache Maven.
2. **Demonstration:** Provide tangible evidence of Maven knowledge through executable projects, troubleshooting labs and real-world build scenarios.

This repository documents a practical journey through Apache Maven, from fundamental concepts to production-oriented Java builds.

The goal is not simply to learn Maven commands, but to understand how Maven works internally and how to use it effectively from the terminal.

## What This Repository Demonstrates

- Maven project structure
- POM configuration
- Dependency management and scopes
- Transitive dependencies
- Dependency conflict resolution
- Build lifecycle
- Plugins and goals
- Maven Wrapper
- Profiles
- Parent POMs and BOMs
- Multi-module projects
- Spring Boot applications
- CI/CD integration
- Build quality and security
- Troubleshooting
- Reproducible builds

## Practical Labs

Each laboratory focuses on specific Maven concepts through executable projects, terminal commands, output inspection and practical verification.

| Lab | Topic |
|---|---|
| `14-spring-boot` | Spring Boot application, dependency packaging, executable JARs and HTTP endpoint verification |

## Learning Approach

The laboratories follow a practical workflow:

1. Understand the concept.
2. Predict the expected result.
3. Execute the command.
4. Inspect the output and generated artifacts.
5. Investigate relevant implementation details.
6. Document the findings.

## Java Compatibility

The repository includes hands-on work with multiple Java versions, focusing on compilation configuration, runtime requirements and compatibility.

## Portfolio Objectives

Demonstrate practical experience with Maven dependency management, lifecycle customization, plugin configuration, multi-module builds, troubleshooting, reproducible builds and CI/CD integration.
